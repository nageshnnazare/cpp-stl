# Containers

Each file is one type: picture, CRUD, a job it wins, why not the
runner-up, related problems, and a runnable example.

| File | One-line job |
| --- | --- |
| [`vector.md`](vector.md) | default growable array |
| [`deque.md`](deque.md) | O(1) both ends + index |
| [`list.md`](list.md) | O(1) erase of a held node |
| [`forward_list.md`](forward_list.md) | singly linked, tiny nodes |
| [`array.md`](array.md) | fixed N, no heap |
| [`string.md`](string.md) | text on a contiguous buffer |
| [`set.md`](set.md) | ordered unique / delete-anywhere heap |
| [`map.md`](map.md) | ordered key → value, predecessor |
| [`unordered_set.md`](unordered_set.md) | seen-set |
| [`unordered_map.md`](unordered_map.md) | frequency, Two Sum, graphs |
| [`stack.md`](stack.md) | LIFO, monotonic next-greater |
| [`queue.md`](queue.md) | BFS |
| [`priority_queue.md`](priority_queue.md) | top-k, Dijkstra |
| [`span.md`](span.md) | non-owning slice |
| [`string_view.md`](string_view.md) | non-owning text |
| [`bitset.md`](bitset.md) | packed compile-time flags |
